# Porto Digital — conectando histórias, transformando o futuro

Site estático em HTML, CSS e JavaScript sobre o Porto Digital, no Recife. Inclui narrativa em três períodos, indicadores e fontes, mapa, galeria com créditos e licença, e layout responsivo.

## Executar localmente

Abra `index.html` em um navegador. As imagens locais ficam em `imagens/`; fontes, mapas e parte das fotografias dependem de conexão com a internet.

As fontes e os créditos de imagens estão na própria página. Verifique a licença na página de origem antes de reutilizar as imagens em outros projetos.
